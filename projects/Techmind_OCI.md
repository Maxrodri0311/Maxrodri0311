# ☁️ Techmind: High-Performance OCI Deployment & Integration

## 📌 The Business Context
Techmind is an intensive work simulation in collaboration with Oracle, No Country, and Alura Latam. Operating in a cross-functional team of 6 engineers, the core challenge was to orchestrate a seamless integration between Data, Backend, and Frontend modules and deploy the entire ecosystem to **Oracle Cloud Infrastructure (OCI)**.

## 🛠️ The Architecture & Trade-offs
- **Cross-Functional Orchestration:** I led the revision of the OCI Integration Plan coordinating across 3 distinct sub-teams. This required intense communication, architectural mapping, and strict version control.
- **Cloud-Native Deployment (OCI):** 
  - Provisioned Virtual Cloud Networks (VCNs) and IAM policies to ensure **least-privilege access** and network isolation.
  - Deployed the Backend ensuring high availability and secure data ingestion from the Frontend and Data layers.
- **Security & Observability:** Implemented distributed tracing and strict auditing protocols (leveraging my IBM Cybersecurity framework) to monitor API latency and detect unauthorized access attempts across the OCI instances.

## 📈 Quantifiable Impact (STAR Metrics)
- **Successfully orchestrated** a complex multi-node deployment to OCI, syncing Data, Backend, and Frontend deliverables on a strict timeline.
- **Secured** cloud infrastructure by applying GRC (Governance, Risk, and Compliance) principles directly to OCI IAM and VCN routing rules.
- **Bridged** the gap between data engineering and cloud architecture, functioning as a "Cross-Functional Technical Specialist".

## 🛡️ Seniority Signals
- **Leadership & Communication:** Proactively managed the technical integration points between isolated teams.
- **Architectural Discipline:** Treated cloud infrastructure not just as hosting, but as a defined, secure, and observable environment.
